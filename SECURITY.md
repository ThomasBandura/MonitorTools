# Security Policy

## Supported Versions

Only the latest release receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security problems. Report them privately through
[GitHub Security Advisories](https://github.com/ThomasBandura/MonitorTools/security/advisories/new).

Include the affected implementation (PowerShell module or C# CLI/library), the version and steps to reproduce.
You can expect a first answer within a week.
